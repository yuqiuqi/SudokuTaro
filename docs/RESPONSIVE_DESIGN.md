# 方寸数独自适应设计

现行规则对应 v1.3.0；本轮按难度分层数字辅助、去除新局按钮白色内边沿、增加两处再赏流光及前三课五步演示。棋盘与键帽增加实体厚度，保持平整正视布局。视觉沿用[确认的 Figma V2](https://www.figma.com/design/AhWwkAjjXti2imJAbhgrTY?node-id=20-545) 雾蓝／浅青光晕、玻璃工具和悬浮棋盘；使用系统字体与真实 CSS 像素，不下载 SF Pro。此前高屏键盘独立钉底的版式记录见 [v1.2.0](releases/v1.2.0.md)。

## 可用空间与共享主列

布局按 `visualViewport` 实际可见 CSS 宽高、安全区和可用分区计算，不读取设备型号或物理分辨率。`ResizeObserver` 与 `visualViewport.resize` 触发重算，旋转和分屏保留局面。parent 的实际安全可用高度作为预算，防止自然内容高度反过来缩减预算；模式分类单独使用稳定的 20px／安全区基准，避免模式自身的 padding 触发振荡。

手机标题、状态、棋盘和数字面板共享 `--board-size` 主列，工具组在主列内略收窄并保留真实按钮间隔。左右最小留白各 14px，安全区优先；棋盘外框最大 414px。高度受限时先收紧头部与说明开销，再让整列一致收窄。紧凑头部 52px，选格说明与冲突反馈共用固定 28px 反馈行；错误出现、自动到期或手动关闭均不参与棋盘预算。

普通手机统一 5/4 两排数字，数字真实高度 45px、工具按钮真实点击高度 44px；工具到数字面板 10px。完整游戏组用上下 auto margin 分配剩余高度，数字区不独立钉底。320×480 为受限回退：整列及棋格缩小，工具高度 34px、组间距 8px；数字高度仍 45px，但宽度约 33px。保留全部操作不代表它与普通手机有相同触控舒适度。

宽屏／低矮横屏保留左棋盘、右工具与 3×3 数字，极短横屏工具与数字并列，数字高度随真实可见空间缩减。280×320 按实际可用宽度同时预算棋盘和右侧控制区，保留至少 90px 棋盘与左右 14px 留白；控制区在该尺寸回退至 146px，此值不作为所有宽屏的最小值。浏览器提供左右／上下分区信息时，限制棋盘并预留分区间隙；未提供时按实际视口回退，不承诺识别所有折痕。主页面不使用 ScrollView，不以隐藏溢出代替真实可见性检查。

## 新手、弹窗与工具

教程分七页解释行、列、3×3 宫、填数状态、工具、免费提示与高亮，以及新局／保存／语言。前三页提供真实 81 格的行／列／宫示例，以中央缺少的 9 演示识别单元、观察八个数字、找缺数、选空格、填入并验证五步；只表示该单元完成。默认第 1 步静止，原生 1–5 步骤按钮带当前态，手动选择即停止自动演示。「观看演示／暂停演示」每 1600ms 推进一步，至第 5 步停止，末步可从第 1 步再次开始。切页、关闭及新局卸载清除定时器；隐藏页或启用减少动态效果停止自动演示，后者仍可手动选步。演示与真实游戏、计时及存档隔离。

演示解说使用不可访问的自然尺寸副本预留最大高度，仅当前解说通过 status／aria-live 表达。常规步骤控件最小高度 44px；受限容器（高度不超过 390px）回退至 32px，81px 图在左，完整正文、解说与控件在右；宽度不超过 399px 时控件跨整行。中等高度手机收紧教程上下留白而保留 44px 步骤控件；窄短屏的其他四课允许正文绕图并使用完整宽度，避免英文长文案挤出底部。语言项始终保留 44px。七页分页和进度仍由数据长度驱动，其他四课图解保留；240px 高横屏进度沿用头部空位。

上方新增新局入口，打开现有难度选择弹窗；选择难度才替换局面，关闭保留原局与存档。原难度及设置入口保留。本轮 accent 新局按钮改用同色边框与柔和外阴影，去除白色 inset 并保留键盘焦点环；主头继续使用 52px／32px 的尺寸预算回退，极小屏使用短标签。

各弹窗（含胜利）使用同一中文／English 显式选择，以高亮、勾选与 `aria-pressed` 表达状态。所有尺寸的语言选项均高 44px，短屏也保留两项和弹窗操作完整可达；只有其他控件按既有空间预算回退。当前语言重复点击不切换，偏好随保存恢复。

棋盘普通格线为低饱和灰蓝，宫线稍深，避免抢过选格与数字强调色。四工具键留出真实 gap，组宽相对主列略收窄；普通高度仍为 44px。普通手机真实横向 gap 为 8px，高度受限手机为 5px，极短横屏竖排为 4px；历史操作回归实际点击间隙并确认不会触发工具；本轮需持续保留该检查。短屏仍按可用空间调整其他尺寸。

振动设置先检测浏览器 Vibration API。缺少 API 时开关禁用、有效 `aria-checked=false`，并以 `aria-describedby` 关联中英文原因；保存偏好可保持开启，但能力缺失时不生效。支持设备保留用户手势中的 API 调用。iOS Safari 不支持 Vibration API（本地 caniuse-lite 的 27.2 条目仍为 n）；本轮不以声音、摇动或控件技巧代替触觉，也未进行 iOS 真机测试。

## 实体材质与按压反馈

棋盘使用 4px 实体底沿、接触阴影及左上高光，格面浅倒角与数字轻浮雕保持 81 格平整清晰。工具键采用静态浅浮起质感；数字键以 2px 基座呈现凸起，按下轻沉 1px 并收紧阴影；减少动态效果时取消位移与过渡，保留颜色和阴影反馈。材质不改变主列边线、既有布局预算或操作顺序，按钮真实点击区域继续由几何与实际操作回归检查。

## 可编辑输入与稳定提示

给定格采用原生 `disabled` 并显式保留 `opacity:1`，保持数值、深色与给定标签，不能被点击、Tab、Enter／Space 或方向键选中；choose／fill 继续作防御。箭头在原行／列中跳过给定数，无目标时保留原格；无选择时取首个可编辑格，没有可编辑格时安全返回。选格同步真实 `focus({preventScroll:true})`。其他同数、同行列宫或提示区域的辅助高亮不附带当前选中框。

数字与格子使用原生 button，无 input、textarea 或 contenteditable，不因游戏输入唤起系统键盘。笔记、擦除、撤销与冲突拒绝保留；四角选中框继承并限幅外缘圆角。新局检查唯一解，实际给定数字按简单 36–40／中等 31–35／困难 26–30 严格分档；生成最多尝试两次，再以唯一解模板兜底。旧存档不受新范围限制。此为线索数量分档，未作专业逻辑技巧难度评级。

简单模式选中可编辑格时，1～9 按当前行／列／宫已有数字设置原生 `disabled`，配合灰色禁用态；排除当前格自身，不参考 solution，换格、填数、擦除和撤销后重算，笔记不新增冲突候选。中等／困难的 1～9 保留同等可选外观，允许玩家手工增删错误候选并撤销；已填格不能写笔记、给定格只读、胜局不再填数仍保留。全部难度的正式填数继续拒绝冲突并保留稳定反馈，不把非法数写入棋盘。未选格仍提示先选格；难度按保存值判断，无须迁移旧档。各状态不改变键帽尺寸或布局预算。

分层提示当前免费。广告说明与观看按钮仅在未来真实 provider 已接入且 ready 后显示；就绪前保留现有免费入口。观看需先确认，只有完整观看的 rewarded 结果才发放提示，取消或失败不计提示次数；重复点击与迟到回调不能重复发放。本轮没有真实广告 SDK，也没有模拟广告或奖励。

提示在棋盘外替换操作区，不自动填答案。标题／正文用 `aria-hidden`、不可交互的自然尺寸副本预留全部层数的最大空间；仅 active 文案可访问，换层按钮可原坐标连续点击。开启、换层和关闭不改变棋盘／状态几何。末层将焦点交给「我来试试」；设置切新局保持内部焦点，关闭回到最初 opener。极短横屏提示说明按完整正文自然使用 14／28px，恢复填数后回到固定 42px 错误槽。

## 胜利流程与再赏流光

81 格按 `row + column` 错开 90ms，960ms 单格包络组成 2400ms 彩虹波浪；最后一格真实 `victory-wave` animationend 启动 650ms 青柠缝隙光，其真实 `victory-seam-light` animationend 揭晓成绩。无填充 SVG 光层覆盖格缝、宫界与外缘，格面与数字不变，光层不可交互；不使用固定延时推断结束。

结果卡和完成棋盘操作区均提供「再赏流光／See the glow」，只允许完成态进入，复用上述 animationend 链并回到成绩。两处操作组保持同一行三列，短屏紧凑布局；不改变棋盘、用时、落笔、提示、胜场、最佳成绩或保存，也不重复首次胜利振动。演出中入口禁用并防重复触发；减少动态效果时入口禁用，以可见原因及 `aria-describedby` 解释。

减少动态效果直接展示结果，庆祝中启用该偏好也立即结束；Escape、设置、新局保留取消行为，刷新不重播、不重复记胜场。小屏成绩卡和极短横屏棋盘／成绩并列保持奖章与全部操作可达；「欣赏棋盘」及重新查看成绩保留焦点恢复。
