# 方寸数独自适应设计

现行规则对应 v1.2.3；本轮增加可用数字状态与提示接入预留。棋盘与键帽增加实体厚度，保持平整正视布局。视觉沿用[确认的 Figma V2](https://www.figma.com/design/AhWwkAjjXti2imJAbhgrTY?node-id=20-545) 雾蓝／浅青光晕、玻璃工具和悬浮棋盘；使用系统字体与真实 CSS 像素，不下载 SF Pro。此前高屏键盘独立钉底的版式记录见 [v1.2.0](releases/v1.2.0.md)。

## 可用空间与共享主列

布局按 `visualViewport` 实际可见 CSS 宽高、安全区和可用分区计算，不读取设备型号或物理分辨率。`ResizeObserver` 与 `visualViewport.resize` 触发重算，旋转和分屏保留局面。parent 的实际安全可用高度作为预算，防止自然内容高度反过来缩减预算；模式分类单独使用稳定的 20px／安全区基准，避免模式自身的 padding 触发振荡。

手机标题、状态、棋盘、工具和数字面板共享 `--board-size` 列宽。左右最小留白各 14px，安全区优先；棋盘外框最大 414px。高度受限时先收紧头部与说明开销，再让整列一致收窄。紧凑头部 52px，选格说明与冲突反馈共用固定 28px 反馈行；错误出现、自动到期或手动关闭均不参与棋盘预算。

普通手机统一 5/4 两排数字，数字真实高度 45px、工具按钮真实点击高度 44px；工具到数字面板 10px。完整游戏组用上下 auto margin 分配剩余高度，数字区不独立钉底。320×480 为受限回退：整列及棋格缩小，工具高度 34px、组间距 8px；数字高度仍 45px，但宽度约 33px。保留全部操作不代表它与普通手机有相同触控舒适度。

宽屏／低矮横屏保留左棋盘、右工具与 3×3 数字，极短横屏工具与数字并列，数字高度随真实可见空间缩减。280×320 按实际可用宽度同时预算棋盘和右侧控制区，保留至少 90px 棋盘与左右 14px 留白；控制区在该尺寸回退至 146px，此值不作为所有宽屏的最小值。浏览器提供左右／上下分区信息时，限制棋盘并预留分区间隙；未提供时按实际视口回退，不承诺识别所有折痕。主页面不使用 ScrollView，不以隐藏溢出代替真实可见性检查。

## 实体材质与按压反馈

棋盘使用 4px 实体底沿、接触阴影及左上高光，格面浅倒角与数字轻浮雕保持 81 格平整清晰。工具键采用静态浅浮起质感；数字键以 2px 基座呈现凸起，按下轻沉 1px 并收紧阴影；减少动态效果时取消位移与过渡，保留颜色和阴影反馈。材质不改变主列边线、既有布局预算或操作顺序，按钮真实点击区域继续由几何与实际操作回归检查。

## 可编辑输入与稳定提示

给定格采用原生 `disabled` 并显式保留 `opacity:1`，保持数值、深色与给定标签，不能被点击、Tab、Enter／Space 或方向键选中；choose／fill 继续作防御。箭头在原行／列中跳过给定数，无目标时保留原格；无选择时取首个可编辑格，没有可编辑格时安全返回。选格同步真实 `focus({preventScroll:true})`。其他同数、同行列宫或提示区域的辅助高亮不附带当前选中框。

数字与格子使用原生 button，无 input、textarea 或 contenteditable，不因游戏输入唤起系统键盘。笔记、擦除、撤销与冲突拒绝保留；四角选中框继承并限幅外缘圆角。新局检查唯一解，实际给定数字按简单 36–40／中等 31–35／困难 26–30 严格分档；生成最多尝试两次，再以唯一解模板兜底。旧存档不受新范围限制。此为线索数量分档，未作专业逻辑技巧难度评级。

选中可编辑格时，1～9 按当前行／列／宫已有数字设置原生 `disabled`，配合明显不同的禁用色。排除当前格自身，只判断当前棋盘约束，不参考 solution；换格、填数、擦除和撤销后重算。笔记禁止新增冲突候选。未选格时数字键仍可触发先选格说明；已有选择时禁用按钮不产生冲突反馈，实体键盘的非法数字输入仍拒绝并保留原有稳定反馈槽。禁用状态不改变键帽尺寸或布局预算。

分层提示当前免费。广告说明与观看按钮仅在未来真实 provider 已接入且 ready 后显示；就绪前保留现有免费入口。观看需先确认，只有完整观看的 rewarded 结果才发放提示，取消或失败不计提示次数；重复点击与迟到回调不能重复发放。本轮没有真实广告 SDK，也没有模拟广告或奖励。

提示在棋盘外替换操作区，不自动填答案。标题／正文用 `aria-hidden`、不可交互的自然尺寸副本预留全部层数的最大空间；仅 active 文案可访问，换层按钮可原坐标连续点击。开启、换层和关闭不改变棋盘／状态几何。末层将焦点交给「我来试试」；设置切新局保持内部焦点，关闭回到最初 opener。极短横屏提示说明按完整正文自然使用 14／28px，恢复填数后回到固定 42px 错误槽。

## 保留的胜利流程

81 格按 `row + column` 错开 90ms，960ms 单格包络组成 2400ms 彩虹波浪；最后一格真实 `victory-wave` animationend 启动 650ms 青柠缝隙光，其真实 `victory-seam-light` animationend 揭晓成绩。无填充 SVG 光层覆盖格缝、宫界与外缘，格面与数字不变，光层不可交互；不使用固定延时推断结束。

减少动态效果直接展示结果，庆祝中启用该偏好也立即结束；Escape、设置、新局保留取消行为，刷新不重播、不重复记胜场。小屏成绩卡和极短横屏棋盘／成绩并列保持奖章与全部操作可达；「欣赏棋盘」及重新查看成绩保留焦点恢复。

## 回归验证与边界

v1.2.3 类型检查、26 项逻辑测试、根路径／Pages 生产构建与完整浏览器回归均通过，两轮运行时错误为空；独立 AI 代码与最终两图视觉审查无未解决 P0／P1／P2。八组几何在两路径重新测量一致。默认免费提示 UI 已做浏览器回归；未来 provider-ready 广告确认弹窗的焦点／交互与真实 SDK 未进行浏览器或真机实测，奖励控制器由逻辑测试与接线代码审阅验证。本轮截图来源、执行记录与边界见 [v1.2.3 更新说明](releases/v1.2.3.md)。

需持续保留的回归范围：

- 14px 最小留白、280×320 控制区可达；普通／减少动态效果下真实 pointerdown 的按压深度、尺寸及页面几何稳定。
- 八组中英文整版几何、主列边线、主要手机棋盘占比、数字／工具真实目标、操作组间距及整体居中；320×480 英文头部完整。
- 给定格 pointer／click／Tab／Enter／Space 不可选，方向键连续跳过、原行列边界无目标保持、真实焦点跟随；无选择、新局、恢复与提示 review 路径，以及同数辅助高亮。
- 数字键按行／列／宫禁用、排除自身且不依赖答案，换格／填擦／撤销重算，笔记不能新增非法候选；未选格提示与实体键盘冲突拒绝。免费提示入口、provider 不可用时隐藏广告、ready 确认、rewarded 发放、取消／失败／重复点击／迟到回调边界。
- 错误前／出现／到期／手动消失，提示开启／各层／关闭的几何稳定；single／hidden／review／explore 双语实际长文案及同坐标操作；临界尺寸连续 60 帧稳定。
- 全部 81 格、数字 1～9 与工具在实际可视区内，无双向文档滚动；逐个数字实际点击、笔记、撤销、冲突、旋转／刷新存档。
- 568×240、480×240 数字 7～9 实际点击；中英文新局、规则、设置和通关操作；390×720 压缩到 `visualViewport.height=400`；左右／上下分区模拟与英文长成就。
- 波浪真实 Z 位移／倾角及对角延迟；暂停末格／光层直到真实结束事件才推进；五视口全部 81 格中央像素不变、光不挡点击；两阶段取消、刷新仅记一次胜场及动态减少动效。
