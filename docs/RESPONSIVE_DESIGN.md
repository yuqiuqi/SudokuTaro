# 方寸数独自适应设计（旧院 2.0 候选）

当前源码采用React18/Vite和原生DOM，暖瓷棋盘、墨绿控件、纸页菜单与独立SVG旧院。2.0.0尚未发布，线上仍为v1.3.0，最终用户审核闸门见[AGENTS](../AGENTS.md)。旧雾蓝玻璃Figma方案与旧测量属于历史，见[v1.3.0](releases/v1.3.0.md)，不能代表本候选截图或验证。

## 可用空间

`useGameLayout.ts`按真实CSS像素、`visualViewport`、安全区和可用分区预算空间，响应ResizeObserver及视口变化。parent实际安全高度是预算，不以内容自然高度反推；模式分类使用独立稳定基准，防止padding反馈振荡。旋转与分屏保留棋局，不按设备型号猜布局。

手机标题、状态、棋盘和数字区共享`--board-size`主列，左右最少14px（安全区优先），棋盘最大414px。普通手机5/4两排数字，数字高45px、工具目标44px、工具到数字10px，完整游戏组居中而非键盘独立钉底。320×480等受限屏缩小整列，工具可回退34px、组间距8px，数字宽度随主列缩小；几何完整不等于普通手机的触控舒适度。

品牌现在是手动故事入口。高度充足的普通手机使用44px入口和64px总头部预算，390×720保持既有棋盘预算；受限屏保留32px入口及原52px／32px头部回退。该小目标是明确妥协，不扩大透明命中区覆盖状态行。完整场景不挤进游戏顶部横条。

宽屏／矮横屏采用左棋盘、右工具与3×3数字；极短横屏工具与数字并列，实际高度回退。280×320按可用宽度预算两区，保留最小棋盘与留白，不将最窄控制区尺寸套用所有宽屏。存在浏览器分区信息时预留分区间隙，否则按视口回退；不保证识别全部折痕。

## 游戏、弹窗和故事阅读

游戏页面不应上下或左右滚动，也不能以隐藏overflow掩盖裁切。全部81格、九个数字和相关操作必须在实际可视区内。故事是唯一新增的正文内部滚动场景：单一dialog中固定头部语言／关闭、固定底部翻页，reader可聚焦并独立纵向滚动；游戏文档不随之滚动。目录与正文使用真实DOM，切篇／切语言重置滚动，首末章禁用翻页仍保留焦点，关闭回入口。

新局先选难度才替换，取消保留原局。中英语言项在所有尺寸保留44px。七页教程、前三课五步演示、默认静止、1600ms有限自动以及切页／关闭／hidden／reduced停止继续保留。中英文长文案和240px横屏须实际检查，不用缩略文字替代全文。

## 材质、语义和输入

暖瓷实体棋盘最突出，工具较轻、键帽有基座、菜单如纸页。统一左上柔光，给定数为深墨、输入为青绿、候选保持清晰，冲突使用独立暖红；危险状态内环与背景优先于普通给定／输入／选中状态。禁用态与题面可读性分别处理，不靠降低整盘透明度。

原生button实现数字／格子，不使用隐藏输入或contenteditable。给定格原生disabled，仍保留可读值与标签；不能指针、Tab或Enter选中。方向键在原行列跳过给定格，无目标保持当前格，真实焦点随选择`preventScroll`。简单模式基于当前行列宫禁用冲突数字，中高难度保留九键和手工笔记，全部难度仍拒绝冲突正式填数。

错误和分层提示使用稳定空间，不改变棋盘几何。提示通过不可访问的自然尺寸副本预留最大正文，仅当前文案可访问。普通工具保留真实间隙；实际点击空隙不应触发工具。焦点环必须可见，故事reader包含在现有dialog焦点循环内，不嵌套第二层overlay。

## 动态与能力

普通落笔140ms局部反馈，首次完成单元260ms柔光，键帽按下最多1px；不移动或缩放整盘。旧院新物件600ms一次opacity显现，门灯9s与风铃8s低幅循环。hidden/reduced停止相应动态，仍保留静态状态、手动教学与阅读。一次显现收据和已读／解锁分开。

原胜利保持2400ms对角彩虹波浪→650ms青柠缝隙光→结果，两段均依赖真实animationend。再赏复用演出，不记胜、不发章、不重复振动；reduced禁用再赏并给可见原因。结果里的故事是主动入口，保留原胜利操作。隐藏、设置、新局、Escape及动态偏好变化须清理演出。

振动依赖浏览器Vibration API。缺失时开关disabled、有效状态false并提供关联原因；保存偏好不能绕过能力限制。未做真实iOS触觉验证。
