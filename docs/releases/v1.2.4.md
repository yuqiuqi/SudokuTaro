## 振动与验证边界

iOS Safari 不支持 Vibration API；本地 caniuse-lite 的 iOS Safari 27.2 数据仍标记为不支持。仅 H5 不能强行提供该平台原生触觉，本轮未使用声音、摇动或控件技巧模拟替代，也未做 iOS 真机实测。其他浏览器是否振动仍取决于实际 API、设备与系统行为。

浏览器 CSS 视口与分区模拟不代替移动 Edge、iOS Safari、屏幕阅读器、真实地址栏伸缩、安全区或折叠硬件实测。极小／极短屏几何完整不等于普通手机触控舒适度。未来 provider-ready 广告确认弹窗的焦点／交互及真实 SDK 未做浏览器或真机实测，奖励控制器由逻辑测试与接线审阅验证；广告仍需真实 SDK 接入及平台实测，当前提示继续免费。
