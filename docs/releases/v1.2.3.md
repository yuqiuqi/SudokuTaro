# v1.2.3 · 可用数字与提示入口

## 更新内容

- 选中可编辑格后，所在行、列或九宫格已有的数字键禁用，并以不同颜色区分。判断依据当前棋盘，不依据答案；已填可编辑格排除自身，换格、填数、擦除与撤销后同步更新。
- 笔记不能新增冲突候选；未选格仍提示先选格，实体键盘输入冲突数字仍拒绝并保留稳定反馈。禁用数字键不触发点击反馈。
- 分层提示当前继续免费。预留未来广告入口，只有真实服务已接入且可用后才显示观看说明与按钮；观看需确认，完整观看并获得奖励结果才发放提示，取消或失败不增加提示次数，重复点击与迟到回调不能重复发放。本轮未接入真实广告 SDK，不模拟广告或奖励。
- 保留实体棋盘与凸起键帽、14px 最小留白、共享主列、只读题面、同数辅助、存档兼容，以及彩虹波浪 → 青柠缝隙光 → 成绩流程。

## 验证与独立审阅

本轮最终类型检查、26 项逻辑测试、根路径生产构建／完整浏览器回归及 GitHub Pages 子路径构建／完整浏览器回归均通过，两轮浏览器运行时错误为空。本地生产部署验证器预检通过；此预检不等于线上部署验证。构建保留已有 Webpack 入口体积提示。

逻辑与浏览器回归覆盖可用数字计算、禁用状态与真实点击、笔记与实体键盘冲突路径、换格／填擦／撤销后更新，以及默认未配置广告时的免费提示 UI。UI 实际复用的奖励请求控制器由 deferred 逻辑测试验证重复请求、取消后的迟到奖励与旧新请求交错等边界，接线由代码审阅核对；这不代表广告观看端到端成功。未来 provider-ready 广告确认弹窗的焦点与交互、真实 SDK 均未进行浏览器或真机实测，正式接入前需补充验证。

八组手机几何在根路径与 Pages 产物中重新测量，结果相同并与 v1.2.2 一致：393×720 棋盘 365px、430×932 棋盘 402px，左右均为 14px；完整结果与保留场景见 [自适应设计](../RESPONSIVE_DESIGN.md)。

README 两张新图来自本轮最终 Pages 子路径生产构建，在真实界面新开中等局面后选中可编辑格采集；初始给定数为 32，品牌为「方寸数独」，展示可用键与灰色平底禁用键。截图元数据和日志记录采集来源，采集未报告运行时错误；旧实体材质状态图保留原文件。

独立 AI 代码与最终两图视觉审查无未解决 P0／P1／P2；可用数字蓝色凸起与禁用数字灰色平底区别清楚，题面可读，主列比例保持。独立 AI 截图审阅只覆盖其实际看到的静态画面，不能证明点击、焦点、无滚动、奖励回调或胜利流程；交互与逻辑结论以实际执行的回归为准。没有进行真实广告观看验证。
