## 仓库权限的实际结果

审计时 main 没有保护。当前云连接对分支保护正式 PUT 及简介 PATCH 均收到 GitHub `403 Resource not accessible by integration`；未成功启用保护，也未成功更改远端 About。账号具有仓库管理员身份不等于连接被授予 Administration 权限。配置文件已准备并经独立审阅，但不是已生效证据；需管理员网页应用或为连接提供对应权限。没有改私有、没有限制公开读取的虚假设置。

main 方案要求 PR、两项绑定 GitHub Actions 的严格最新检查、讨论解决、管理员适用和禁止强推／删除。单人维护不强制他人批准；检查成功不等于人工审查。没有把 PR 会跳过的部署任务设为必需检查。
