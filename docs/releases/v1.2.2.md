# v1.2.2 · 方寸数独、实体棋盘与凸起键帽

## 更新内容

- 产品显示名统一为「方寸数独」；原仓库名、访问网址和存档标识保持兼容。
- 修复简单／中等线索数量可能相同的问题：新局按实际给定数分为简单 36–40／中等 31–35／困难 26–30，挖洞后验收，最多尝试两次再以唯一解模板兜底。旧存档完整保留；线索分档不代表专业逻辑技巧难度评级。

- 棋盘增加 4px 实体底沿、接触阴影与统一左上高光；格面采用浅倒角和轻微数字浮雕，保留平整正视布局与清晰题面。
- 工具键采用静态浅浮起质感；数字键采用 2px 基座的凸起键帽，按下轻沉 1px；减少动态效果时取消位移与过渡，保留颜色及阴影反馈。
- 左右最小留白由各 6px 增至各 14px，安全区优先；延续共享主列、5/4 两排数字与整组上下平衡，并修复 280×320／280×470 极窄横屏右侧控制区越界。
- 保留只读题面、同数辅助、稳定反馈／分层提示、笔记与撤销、存档及彩虹波浪 → 青柠缝隙光 → 成绩流程。版本号为 1.2.2，未新增依赖或改变存档格式。

## 验证与独立审阅

本轮方寸数独版本的类型检查、13 项逻辑测试、根路径生产构建／完整浏览器回归及 GitHub Pages 子路径构建／完整浏览器回归均已通过，两轮浏览器未报告运行时错误。逻辑回归包含 180 个确定种子的三档实际线索数、唯一解与答案对应、生成兜底及旧存档兼容。部署验证器已对本地 Pages 生产产物预检通过；此预检不等于线上部署验证。构建保留已有 Webpack 入口体积提示。

根路径构建八组手机几何已测量：393×720 棋盘为 365px、左右各 14px，430×932 为 402px、左右各 14px；393×650 保持 360px 棋盘与各 16.5px 留白，320×480 保持 202px 受限回退。八组数字高 45px，普通手机工具点击高 44px、组间距 10px，小屏工具回退 34px／8px。完整测量与需保留的回归范围见 [自适应设计说明](../RESPONSIVE_DESIGN.md)。

独立 AI 首轮根路径静态视觉／UX 审阅覆盖 393×650、430×932、320×480、568×240 及选中／冲突／提示图，没有 P0／P1／P2 必改项。实体厚度、凸起键帽与统一光源可辨，文字与现有状态保持清晰。该审阅不能证明实际点击、焦点、无滚动或胜利流程；这些由浏览器交互回归另行验证。

README 两张整版图及适配说明两张状态图，均来自最终 Pages 子路径生产构建，经真实界面新开中等局面采集；该局初始给定数为 31，标题为「方寸数独」。状态图在界面变化后等待过渡稳定，全部截图未报告运行时错误。
