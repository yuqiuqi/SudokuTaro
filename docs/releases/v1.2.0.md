# v1.2.0 · 彩虹胜利浪潮

## 更新内容

- 通关庆祝改为左上至右下的对角彩虹波浪。原生 81 格依次抬升、倾斜，伴随深度阴影与彩虹高光，再平缓回落、淡出余辉，数字保持清晰。
- 单格包络 960ms、相邻对角线延迟 90ms，完整波浪约 2400ms。最后一格实际动画结束后才自动显示成绩，不再用固定定时器提前覆盖未落定的格子。
- 减少动态效果跳过波浪；庆祝中动态启用该偏好立即结束动效。Escape、菜单、新局均保留取消行为，关闭菜单不会突然出现旧成绩；刷新不重复庆祝或记胜场。
- 沿用小屏成绩卡及低矮横屏的棋盘／成绩并列布局、欣赏棋盘与再挑战操作；保留存档格式和玩法。没有新增运行时依赖，依赖版本与 v1.1.0 相同。
- 包含此前已授权的 Cursor 文档清理：移除过时的 `.cursor/rules/gsd-sudokutaro.mdc`，将协作与规划入口统一到 `AGENTS.md`，清除 `CONTEXT.md` 及历史计划中对本机 Cursor 规则和技能路径的依赖。历史设计与审查资料继续保留。

## 验证与限制

类型检查、9 项逻辑测试、根路径及 GitHub Pages 子路径生产构建与完整 Playwright / Chromium 浏览器回归均通过，运行时错误为空；保留已有 Webpack 入口体积警告。

新增浏览器断言检查对角传播、真实正 Z 位移及倾角、彩虹高光与阴影、下降／余辉，以及暂停最后一格时不显示结果、真实 animationend 后再揭晓。覆盖 280×320、480×240、568×240 和实际 `visualViewport.height=400` 的波形几何、结束后的点击，以及 Escape、设置打开并提前关闭、新局、刷新和动态减少动态效果。保留原有多视口、输入、笔记、撤销、提示、冲突、双语弹窗、分区模拟和保存回归。

浏览器模拟不代替真实 iOS Safari 或折叠设备验证；极短横屏受现有物理空间限制，棋盘较小。本说明先记录仓库实现及本地验证，远端 CI、部署、标签与正式 Release 需在完成后核实。

实际中段截图与操作说明见 [README](../../README.md)，几何与动画验证方法见 [自适应设计说明](../RESPONSIVE_DESIGN.md)。
