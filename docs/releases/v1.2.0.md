# v1.2.0 · 彩虹浪潮与青柠缝隙光

## 更新内容

- 本轮舒适度修复：提示开关与三层切换保持原棋盘／状态几何，操作按钮可原坐标连续点击，完整中英文长提示不裁切；方向键同步 DOM 焦点，末层提示和设置→新局的焦点连续可操作。
- 修复390×580、844×520/535等临界尺寸的连续模式振荡；实际安全区与棋盘预算保留。极短横屏提示说明采用自然行高，在保持全文和原棋盘的同时使用原操作区空间；可填数时错误反馈槽仍固定。

此前移动布局已随 PR #13 部署；本轮交互舒适度修复仍待发布，下方旧部署证据不代表本轮修复已上线。项目版本号保持 1.2.0，正式标签与 Release 待最终发布核实。

- 冲突提示预留固定空间，出现／自动到期／手动关闭均不再改变棋盘和操作区尺寸；中英文全文仍显示在棋盘外。
- 手机整区左右各 6px（安全区优先）；常规较矮竖屏采用两排大数字，高竖屏使用靠近底部的 3×3 数字区，宽度最多 300px；横屏使用侧边九宫格。保留极小视口的紧凑回退、笔记、撤销及实体键盘行为。

- 通关庆祝改为左上至右下的对角彩虹波浪。原生 81 格依次抬升、倾斜，伴随深度阴影与彩虹高光，再平缓回落、淡出余辉，数字保持清晰。
- 单格包络 960ms、相邻对角线延迟 90ms，完整波浪约 2400ms。最后一格实际动画结束后立即透出单次约 650ms 青柠缝隙光，随后才显示成绩。全部内缝、宫界与外缘具有窄淡亮芯、青柠发光与有限柔光；只沿边界发光，格面保持原样。两次真实 animationend 串联整个过程，不用固定定时器提前覆盖任一阶段。
- 减少动态效果跳过波浪及缝隙光；庆祝中动态启用该偏好立即结束动效。Escape、菜单、新局均保留取消行为，关闭菜单不会突然出现旧成绩；刷新不重复庆祝或记胜场。
- 沿用小屏成绩卡及低矮横屏的棋盘／成绩并列布局、欣赏棋盘与再挑战操作；保留存档格式和玩法。没有新增运行时依赖，依赖版本与 v1.1.0 相同。
- 包含此前已授权的 Cursor 文档清理：移除过时的 `.cursor/rules/gsd-sudokutaro.mdc`，将协作与规划入口统一到 `AGENTS.md`，清除 `CONTEXT.md` 及历史计划中对本机 Cursor 规则和技能路径的依赖。历史设计与审查资料继续保留。

## 验证与限制

此前移动布局已通过完整验证并部署；本轮新增提示／真实键盘焦点、长文案容量与临界尺寸60帧回归。本轮最新类型检查、9 项逻辑、根路径构建及完整 Chromium 全通过，运行时错误为空；Pages／发布状态待本轮流程分别核实。下段及已部署章节属于此前胜利动效验证。

完整两阶段动效通过类型检查、9 项逻辑测试、根路径及 GitHub Pages 子路径生产构建与完整 Playwright / Chromium 浏览器回归，运行时错误为空；保留已有 Webpack 入口体积警告。五种视口的实际像素检查确认全部 81 格中央像素在缝隙光前后不变。

新增浏览器断言检查对角传播、真实正 Z 位移及倾角、彩虹高光与阴影、下降／余辉，以及暂停最后一格时不显示结果、真实 animationend 后立即进入缝隙光；采样缝隙光起光／峰值／衰减的实际透明度、无填充线条、格缝对齐及不变的格面／数字中央样式，暂停光层超过标称时长仍不显示成绩，直到真实结束事件再揭晓。覆盖 280×320、480×240、568×240 和实际 `visualViewport.height=400` 的波形几何、结束后的点击，以及 Escape、设置打开并提前关闭、新局、刷新和动态减少动态效果，两段均验证取消后无残光、无旧成绩、胜场只记录一次。保留原有多视口、输入、笔记、撤销、提示、冲突、双语弹窗、分区模拟和保存回归。

浏览器模拟不代替真实 iOS Safari 或折叠设备验证；极短横屏受现有物理空间限制，棋盘较小。线上功能验证采用下述资源转接方式，不等同于直接在线浏览器实测。

实际中段截图与操作说明见 [README](../../README.md)，几何与动画验证方法见 [自适应设计说明](../RESPONSIVE_DESIGN.md)。
