# v1.3.0 · 自主挑战、再赏流光与分步教学

## 本轮变化

- **按难度提供辅助**：简单模式继续把行／列／宫中冲突数字变灰并原生禁用，排除当前格自身且不读取答案。中等／困难的可编辑格保留 1–9 全部可选，允许手工记录、删除及撤销错误候选。可选不代表正确：所有难度的正式填数仍拒绝冲突，非法数字不入盘。已填格不能写笔记、给定格只读、胜局不再填数等边界保留；难度取保存值，旧存档无须迁移。
- **新局按钮去白边**：accent 按钮用同色边框与柔和外阴影替代白色 inset，保留焦点环、52px／32px 头部预算、极小屏短标签、先选难度再替换及关闭保留原局。
- **再赏流光**：结果卡及完成棋盘均提供「再赏流光／See the glow」，复用 2400ms 彩虹立体波浪 → 650ms 青柠缝隙光 → 成绩，依靠真实 animationend 衔接。演出中防重复触发；不改棋盘、用时、落笔、提示、胜场、最佳成绩或保存，不重复首次胜利振动。Escape／菜单／新局保留取消行为；刷新不自动再演。减少动态效果时入口禁用，并用可见原因及 aria-describedby 说明，演出中启用则立即结束到成绩。
- **前三课五步演示**：行、列、3×3 宫均为真实 81 格，在对应九格中观察 1–8，并向中央空格填入 9。五步依次解释范围、已有数字、缺数、选格、填入验证，只表示该单元完成。默认静止，可手动选 1–5，或每 1600ms 自动推进到末步停止；手动选步会暂停，末步可从头再看。切页／关闭／新局卸载清定时器，隐藏页面或减少动态效果停止自动演示，后者仍可手动切步。示例不改真实局面、计时、纪录或 localStorage。其余四课保留，全部支持中文／English。

- **短屏完整呈现**：中等高度手机收紧教程留白而保留步骤控件尺寸；窄短屏长课文使用图旁及图下空间，极短横屏通关卡收紧紧凑间距，保留完整内容、语言项与操作。

## 保留的兼容性与边界

产品仍为「方寸数独 · Fangcun Sudoku」，仅 H5；GitHub／Pages URL、部署子路径、存档 key 和旧存档保持兼容。保留左右 14px 最小留白、实体棋盘与数字键帽、稳定冲突／提示槽、44px 语言项、候选清理、完整撤销、唯一解生成、免费分层提示与未来广告奖励控制器。未新增依赖，未接入真实广告 SDK；provider-ready 确认界面及真实 SDK 不能视为本轮浏览器或真机通过。

振动仍取决于 Vibration API；缺少 API 时显示原因并禁用开关。浏览器能力模拟不能代替 iOS Safari 的物理触觉测试。仓库保持公开；main 保护／About 的旧 Administration 403 阻塞仍未解决，本轮读取仍为 403，没有已启用保护或已更新简介的声明，详见[仓库安全说明](../REPOSITORY_SECURITY.md)。
