# v1.2.1 · 手机整体布局与只读题面

## 更新内容

- 手机标题、状态、棋盘、工具及数字面板共用主列，以父容器安全可用高度预算棋盘，避免自然内容高度反馈；紧凑头部 52px，选格说明并入固定 28px 反馈行。
- 普通手机统一 5/4 两排数字，工具至数字面板 10px，完整内容块上下居中；取消高屏数字区独立钉底。393／407×650 棋盘外框为 360px，412×700 为 400px，430×932 为 414px；320×480 单独回退至 202px。
- 给定数原生 disabled 且保持不透明，不可选、修改或进入焦点。箭头同行列跳过，无可达目标时保持原格；保留同数／行列宫辅助高亮与独占可编辑选中框。
- 保留完整双语提示、笔记／撤销、存档、弹窗、低矮横屏与分区，以及彩虹波浪 → 青柠缝隙光 → 成绩的既有流程。版本号为 1.2.1，未新增运行时依赖或改变存档格式。
