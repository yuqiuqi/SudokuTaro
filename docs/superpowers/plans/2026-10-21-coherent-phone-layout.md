# 手机整体比例与固定题面修复

基线：已发布的 v1.2.0（`ce98c4d`）。目标版本 v1.2.1。用户主要场景为小米 17 的移动版 Edge；云端只能模拟可见 CSS 尺寸，不声称完成真机验证。

## 设计与验收

- 棋盘作为主视觉，标题、状态、棋盘、工具与数字面板采用共享主列。充分空间时左右目标各 6px，安全区优先；高度不足时先收紧非棋盘开销，再整体一致收窄。
- 393×650、407×650、412×700 优先验收，棋盘目标达到安全可用宽度的 90% 以上，正常手机数字键实际高度至少 44px。
- 工具与数字区保持 8～16px 间隔，不使用弹性空白将操作组拆开。把额外高度分配到完整内容块上下；正常高屏整组中心目标为可见高度的 48%～53%。
- 黑色给定数保持正常对比且不可选，不进入键盘操作焦点；方向键在既有行列边界内跳过给定数。提示的关联高亮与可编辑选择分开。
- 错误出现／消失、提示开启／换层／关闭保持布局稳定。保留完整双语文案、极短横屏与分区回退，以及彩虹波浪→青柠缝隙光→成绩的既有回归。
- 对比八组实际浏览器截图，独立视觉审阅与功能审阅均完成后再发布。当前没有可用的 H5 UI/UX 专用 MCP 或 skill；不以工具名称代替视觉验收。
