# 难度辅助、流光再赏与分步教学设计

用户四项优化作为同一批次交付，沿用已授权无人监管实施、测试、PR、独立审阅、合并、部署、README、附注标签与正式 Release 流程。版本 v1.3.0；产品仍为方寸数独（Fangcun Sudoku）。

## 设计选择

采用难度驱动的输入辅助、原胜利流程复用、可暂停的单元演示。仅把按钮变亮而仍悄悄过滤高级笔记，会造成操作不一致；复制另一套庆祝动画会增加取消与成绩重复风险；不可控循环教学会让新手错过步骤。因此中高难度允许手工候选、演出复用原动画事件、教学默认静止并提供五步与有限自动播放。

## 1. 数字辅助按难度分层

- easy 保持当前同行／列／宫冲突数字变灰且原生 disabled，排除当前格自身，候选不参考 solution。
- medium、hard 的可编辑格 1–9 均可选择，包括手工笔记；不预先排除，保持数字同等可选外观。已填格不能写笔记、给定格只读、胜局不能再填仍保留。
- 普通填数继续拒绝行／列／宫冲突并显示原稳定反馈，不允许非法盘面破坏唯一解及保存。中高难度允许手工记录错误候选，由玩家自行判断；擦除、撤销、相关候选清理保持既有规则。
- 用难度值判断，旧存档无需迁移。同步中英文说明与教程第六页，不以给定数字数量反推难度。

## 2. 新局按钮边缘

- 现按钮继承玻璃 panel-shadow 的白色 inset 高光；仅给 accent 新局按钮独立的同色边框与柔和外阴影，去除白色内边沿。
- 保留原头部 52px／32px 高度预算、短标签、键盘焦点环、14px 最小整列边距和新局取消行为。

## 3. 再赏流光

- 中文「再赏流光」，英文「See the glow」；结果卡与已完成棋盘操作区均可进入，不使用「重播」。操作组保持同一行三列，必要时紧凑排版；语言项仍 44px。
- 仅完成棋盘可进入；关闭结果卡后重启既有 wave → seams → results，保留 2400ms 彩虹立体浪潮与 650ms 青柠缝隙光，由真实 animationend 衔接。
- 不生成新题，不改变时间、落笔、提示、棋盘、胜场、最佳成绩或保存；刷新不自动再演。不重新触发首次胜利振动。
- 动画中入口 disabled，防重复触发；Escape／菜单／新局与减少动态效果变化继续及时取消，不能出现迟到结果弹窗。
- 减少动态效果开启时入口禁用并提供可访问原因；正在演出时开启偏好立即结束到结果。键盘焦点继续按已有结果／完成控件恢复。

## 4. 教程框内五步演示

- 前三课分别演示行、列、3×3 宫，保持真实 9×9、正确九格高亮及 1–9 约束。每个演示只说明对应单元完成，不把一行完成当全盘通关。
- 共五步：识别范围 → 观察八个已有数字 → 找出缺少的数字 → 选中空格 → 填入并验证。使用有效示例，目标为中央格的 9，其他示例数字来自合法排列。
- 默认第 1 步静止；原生 1–5 步骤按钮、当前步状态与简短解说。可从任意步点击，支持「观看演示／暂停演示」，自动播放有限次到第 5 步即停，不无限循环。
- 切页／关闭／新局卸载均清除计时器；隐藏页面或启用减少动态效果停止自动演示。减少动态效果仍可手动切步，不播放移动动画。
- 新 RulesDemo 负责示例与演示状态；RulesDiagram 委托前三类，其他四课图示保留。主教程仍七页，中英文切换保留明确状态。演示不改真实游戏、计时、记录或 localStorage。
- 使用 transform／opacity 与低饱和强调，单元扫描柔和、不整板闪烁；步骤解说预留最大自然高度，变化不抖动弹窗。
- 常规手机步骤控件高 44px；极短屏按 32px 紧凑目标。240px 高横屏图解与右侧正文／步骤组合，保留全文、所有语言项 44px 和翻页操作。280×320 亦须全部可达，不靠裁切或隐藏演示。
